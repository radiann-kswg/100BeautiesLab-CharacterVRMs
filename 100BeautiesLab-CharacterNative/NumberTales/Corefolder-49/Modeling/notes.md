# コアフォルダ #49 ヨチカ

`Corefolder-49.blend` は編集用、`Corefolder-49.vrm` は VRM 0.x の実行用。Blender 5.3.0 と VRM Add-on 4.10.5 で書き出した。

## デザインと出典

- 公式 CreationsDB の `data/Works_NumberTales/DataBases/db_Primary.json` の Num 49、`Images/DB_Primary/corefolder/49/emstk_corefolderNTS-49-{1,2}.png`、`catalog/chr-dsgn_catalogNTS-49.png`、`arts/corefolders/2023/art_imgNTS-49-corefolder.png` を照合した。左胸の「49」は `attr/numberMark/attr_numberMarkNTS-49.png`。胴表面の三角とウェイトを写した着脱用メッシュへ載せ、表面から0.9mm外側に置いた。胴のUVには白腹と青い体毛を配した。
- 毛・髪の主色は `#6AA6D7`、淡色の毛先と耳の内毛は `#9BC1E6`。額から中央へ流れる長短の前髪、両耳、側頭の外ハネを同じ頭皮の面でつないだ。耳の青い外縁・白い開口・淡青の内毛が辺を共有する。頭頂の返りは一束で下面を濃くし、独立して揺れる左右の頬毛は横向きに返る。紺色 `#405AB9` と青 `#4378C3` の虹彩に紫 `#BD8AE6` の縦瞳とハイライトを描いた。
- **顔・頬・発音。** 規範 #4 の実VRMで顔の926頂点・15表情・首・頭・眼骨を対応付け、胸を基準に配置した。眼間、眼骨の回転中心、まぶたの開閉はこの実データに従う。口腔・舌・唇の192点は規範 #25 を参照した。奥の目には角度に応じて前髪がかかる。頭と胴の衣装オフ時の外形は規範VRMが基準。固有の髪・耳・胸の番号を別に扱う。
- #25・#93・#22それぞれの公式絵と実VRMを並べて見た。#25・#93は絵の頬の斜線を立体では淡い暖色と小さな白い反射に変え、#25は顔の外周に毛色が回り込む。ヨチカにも同じ面の扱いを採用し、青い側髪の裏側には一段濃い色を置いた。虹彩下部の丸い色面と墨の輪郭は#4・#25の実アトラスを参照し、ヨチカ固有の青・紫と照明方向を個別UVに描いた。6組の比較は `Corefolder-Training/production-review/reference-pairs.png`。
- **尻尾は9本。** `attr/tailsUnit/attr_tailsUnitNTS-49.png` の上4本・下5本を参照した。後ろの7本は共通素体の尾194頂点・224面の丸い断面を、各房の根元から先まで実アトラスの横断幅に沿って曲げた。上4本は双尖の接合部を滑らかな単一表面にし、髪と区別できる丸い厚みを持たせた。前の2房は細い根元で腹の脇を回り、膨らんでから淡い毛先が返る。左右の前後・高さを少し変え、側面でも2房が重なり切らないようにした。後ろへの張り出しや前房の深さは立体化時の補間。
- **胴の断面。** `Basis/Corefolder/VRCModel_CoreFloder-Base.blend` を読み込み、MirrorとSubdivisionを評価した4,306頂点・8,608辺の順序がスターターと一致することを確認して元座標に戻した。ウェイトと球面UVは編集用モデルに保持した。改稿前の胴は幅1,118mm・奥行947mm、規範#4の実頂点に対応させた胴は幅853.94mm・奥行872.90mm・高さ711.64mm。接地面から50mmで幅497.35mm・奥行534.71mm、100mmで幅653.27mm。前へ回る尾は中腹の厚みを抑えて低く回し、淡青の先を左右に開いた。高さ280mmで側面から胴に重なる尾幅は357.5mmから18.5mm、正面の見える白腹は288.5mmから370.5mmに変化した。180mmでは側面の被覆は617.5mmから642mmに増え、二本の毛の厚みが残る。詳細は `Review/torso-visibility.json`。比較画像は `Review/structure-comparison.png`、16高さの測定は `Review/body-sections.json`。
- 規範 #22 の MToon を基に、白い頬と青の毛束の陰影を調整した。実VRMではBodyに裸胴と後頭部、Faceに表情、Hairに外側の髪と耳、Tailに尾、Outfitに胸番号が入る。後頭部は#4の顔後縁34点と#4・#25・#93の後頭部の実測から作った共通の外殻。尻尾9チェインと頬毛2チェインは規範 #93 のばね設定を参照した。

## 実VRMと原画の投影比較

改稿前のVRMを同一の正投影・光源で−18°、−24°、−30°、−36°から撮影し、外輪郭と両目の中点位置から比較角度を−18°に決めた。改稿後は−18°と正面、側面、背面を再撮影した。Pillow・NumPy・SciPy で不透明部分を切り出し、全高500pxに揃えて色領域を計測した。公式2枚・改稿前・今回の画像は `Review/artwork-comparison.png`、全測定値と書き出しハッシュは `Review/projection.json`、尻尾単体の背面投影は `Review/tail-overlap.png` に記録した。

## 再生成

1. `paint_49.py <CreationsDBのパス>` が白腹・胸番号・顔・前髪・前側の毛先と背面アトラスを生成する。背面の連結領域は共通の `trace_tail_atlas.py` を使う。出力済みの編集画像から続ける場合は省ける。
2. Blender をバックグラウンドで起動し、`model_49.py -- --starter <Corefolder-49-Starter.blend> --out <別の出力先>` を実行する。スターターを再作成する場合は `Corefolder-Training/create_corefolder_base.py` に `--number 49 --style 22 --material CoreFolder022.001 --face-style 22 --face-material CoreFolder022-2.001` と DB・出力先を渡す。
3. `render_measurements.py <VRM> <角度シート.png>` と `compare_49.py <DB> <改稿前シート> <レビュー先> --after <改稿後シート> --before-vrm <改稿前VRM> --after-vrm <改稿後VRM>` で計測を再現できる。

## 頭髪の交差と着脱

額、前髪、側頭の外ハネ、耳の色境界を連続した面で作り、毛束の合わせ目を頭皮UVへ移した。 5群の実VRMを再読込して交線を測定した。正面の別パーツ間の交線は1,707mmから471mmに減少。最終版は同一パーツ内の自己交差も含めて正面487mm、−30°で341mm、＋30°で317mm。小さなデカールと眼球は集計対象外。6方向の値と対象ファイルのハッシュは `Review/head-contacts.json`。番号はOutfitを表示して確認できる。数字の23頂点は裸胴から各0.9mmで、元の胴の頂点と同じスキンウェイト。
