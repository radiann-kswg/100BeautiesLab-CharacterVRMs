# コアフォルダ #49 ヨチカ

`Corefolder-49.blend` は編集用、`Corefolder-49.vrm` は VRM 0.x の実行用。Blender 5.3.0 と VRM Add-on 4.10.5 で書き出した。

## デザインと出典

- 公式 CreationsDB の `data/Works_NumberTales/DataBases/db_Primary.json` の Num 49、`Images/DB_Primary/corefolder/49/emstk_corefolderNTS-49-{1,2}.png`、`catalog/chr-dsgn_catalogNTS-49.png`、`arts/corefolders/2023/art_imgNTS-49-corefolder.png` を照合した。左胸の「49」は `attr/numberMark/attr_numberMarkNTS-49.png` を球面 UV の白腹に焼き込んだ。2023年の絵の白い喉毛は腹側へ続く浅い起伏と毛先の線で表現した。
- 毛・髪の主色は `#6AA6D7`、淡色の毛先と耳の内毛は `#9BC1E6`。左右の面が立った後頭部、中央へ流れる長短の前髪、頭頂の返り、外へ跳ねる頬毛を別々の形状にした。紺色 `#405AB9` と青 `#4378C3` の虹彩に紫 `#BD8AE6` の縦瞳とハイライトを描いた。
- **顔・頬・下顎を分けて編集できる。** 規範 #4 の実VRMで顔の926頂点・15表情・首・頭・眼骨を対応付け、胸を基準に配置した。眼間、眼骨の回転中心、まぶたの開閉はこの実データに従う。口腔・舌・唇の192点は規範 #25 を参照した。奥の目には角度に応じて前髪がかかる。頬から後頭部につながる首・喉の面は顔の後縁から延ばした。下顎は規範の顔を配置した後、頬と胸の接する面に沿って作った。正面の顎縁180点で、中立・開口50%・100%のいずれも頬に隠れた点は0。
- #25・#93・#22それぞれの公式絵と実VRMを並べて見た。#25・#93は絵の頬の斜線を立体では淡い暖色と小さな白い反射に変え、#25は顔の外周に毛色が回り込む。ヨチカにも同じ面の扱いを採用し、青い側髪の裏側には一段濃い色を置いた。虹彩下部の丸い色面と墨の輪郭は#4・#25の実アトラスを参照し、ヨチカ固有の青・紫と照明方向を個別UVに描いた。6組の比較は `Corefolder-Training/production-review/reference-pairs.png`。
- **尻尾は9本。** `attr/tailsUnit/attr_tailsUnitNTS-49.png` の上4本・下5本を参照した。後ろの7本は共通素体の尾194頂点・224面の丸い断面を、各房の根元から先まで実アトラスの横断幅に沿って曲げた。上4本は双尖の接合部を滑らかな単一表面にし、髪と区別できる丸い厚みを持たせた。前の2房は細い根元で腹の脇を回り、膨らんでから淡い毛先が返る。左右の前後・高さを少し変え、側面でも2房が重なり切らないようにした。後ろへの張り出しや前房の深さは立体化時の補間。
- **胴の断面。** `Basis/Corefolder/VRCModel_CoreFloder-Base.blend` を読み込み、MirrorとSubdivisionを評価した4,306頂点・8,608辺の順序がスターターと一致することを確認して元座標に戻した。ウェイトと球面UVは編集用モデルに保持した。改稿前の胴は幅1,118mm・奥行947mm、改稿後は854mm・873mmで、規範#93の854mm・873mmに揃った。接地面から50mmで幅497mm・奥行535mm。首の色を頬の外周とつなぎ、頭頂から前髪の生え際まで毛面を伸ばした。比較画像は `Review/structure-comparison.png`、16高さの測定は `Review/body-sections.json`。
- 規範 #22 の MToon を基に、白い頬と青の毛束の陰影を調整した。書き出し時は編集パーツを4メッシュに集約する。尻尾9チェインと頬毛2チェインは規範 #93 のばね設定を参照した。

## 実VRMと原画の投影比較

実VRMを再読込し、同じ正投影・光源で −18°、−24°、−30°、−36°を撮影した。外輪郭に対する両目の中点位置で改稿前の角度を選び、−18°を改稿後にも固定した。Pillow・NumPy・SciPy で不透明部分を切り出し、全高500pxに揃えて色領域を計測した。公式2枚・改稿前・今回の画像は `Review/artwork-comparison.png`、全測定値と書き出しハッシュは `Review/projection.json`、尻尾単体の背面投影は `Review/tail-overlap.png` に記録した。

原画2枚では手前の虹彩は幅35px・高さ26〜32px、規範の顔に描いたヨチカは幅31px・高さ35px。奥の虹彩は原画の約11〜12pxに対し24px見えている。原画1の近側にだけある右上の反射を描き、両目それぞれの紫の縦瞳が同じ方向を向くよう、反転していた片目のUVを専用の領域に展開した。顔と下顎の同角度拡大を `Review/eyes-and-chin.png` に載せた。

実メッシュの眼球スキンの中心間は#4と同じ200.62mm。中立の上唇から18mm上の頬断面477.37mmに対する比は0.420で、規範6体は0.360〜0.422。全高を揃えた斜視の両虹彩の中心間隔は公式絵より約30px短い。尾の背面投影のIoUはアトラス輪郭を膨らませた前稿0.851から0.820へ変わった。規範の丸い断面と三次元の取り回しによる違いは、上房の根元と前へ回る下房で特に見える。

## 再生成

1. `paint_49.py <CreationsDBのパス>` が胴・顔・喉・前側の毛先と背面アトラスを生成する。背面の連結領域は共通の `trace_tail_atlas.py` を使う。出力済みの編集画像から続ける場合は省ける。
2. Blender をバックグラウンドで起動し、`model_49.py -- --starter <Corefolder-49-Starter.blend> --out <別の出力先>` を実行する。スターターを再作成する場合は `Corefolder-Training/create_corefolder_base.py` に `--number 49 --style 22 --material CoreFolder022.001 --face-style 22 --face-material CoreFolder022-2.001` と DB・出力先を渡す。
3. `render_measurements.py <VRM> <角度シート.png>` と `compare_49.py <DB> <改稿前シート> <レビュー先> --after <改稿後シート> --before-vrm <改稿前VRM> --after-vrm <改稿後VRM>` で計測を再現できる。
