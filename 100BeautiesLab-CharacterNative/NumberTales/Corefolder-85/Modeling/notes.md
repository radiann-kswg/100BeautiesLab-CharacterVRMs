# コアフォルダ #85 ハッコ

編集用ベースは `Corefolder-85-Refined.blend`。公式 CreationsDB の Num 85、`corefolder/85/emstk_corefolderNTS-85-{1,2}.png`、`catalog/chr-dsgn_catalogNTS-85.png`、`arts/corefolders/2023/art_imgNTS-85-corefolder.png` と照合した。

- **顔・耳・髪**　公式の茶髪・シアンの虹彩を #4 由来の表情付き顔に合わせた。中央へ長く落ちる前髪と側ポニー、外向きの毛先を個別の閉じたメッシュにした。両耳の根元を後頭部に重ね、正面右斜めから見える右耳には白い開口・橙の内毛・茶色の折り返しを描いた。左右の高さ・倒れ方と後頭部の奥行きは、公式立ち絵に合うよう補間した。
- **顔面の構成**　規範と同じ眼球・上瞼・眉・内口のトポロジーを維持した。虹彩の濃い上部と青緑の縁は瞼の内側、頬の短線は顔面 UV、本来の下顎の境界は顔と胴が接する高さにある。下顎の線は前面の実際の皮膚表面に沿い、左右端で細くなる。口はそれより上にあり、母音・感情・瞬きのモーフには元の頂点対応を使う。
- **胴・付属品**　共通素体の下半球を横・前後に広げ、肩から頬へつながる褐色の面と球面 UV の白腹を作った。銀色の鎖は実際の胸の曲面に沿わせた。水滴形のシアンの石には濃色の覆輪と吊り環があり、胸ボーンに追従する。茶色は公式 `#C48455` を起点に、規範と同じ Unity ライトを受けた際の明るさを合わせた。
- **可動部**　個別フック `design_85.revise(arm, collection)` がポニー主房・先の枝・左右の頬毛のガイドを返す。主房と枝は同じチェインで揺れる。尾の8房は `Tails-85.json` と `Tails-85.png` に基づく。2枚の公式表情で動く小さな口と、同位置に残る長い顎縁を区別し、口のモーフは共通の仕上げで #93 の口腔形状を参照する。
- **編集画像**　`paint_85.py` は Pillow と NumPy で胴・顔・首・耳左右・髪の UV を再生成する。耳は裏までつながった一枚の曲面で、髪の濃色は各房の先で細く消える。

## 原画と顔の比較

公式立ち絵2枚では、表情が変わっても両目の反射は画面の右上にある。左右の虹彩を別々の UV 領域へ展開し、両方の反射と上部の濃色を同じ照明方向から描いた。頬面・まぶた・眼球を一緒に内へ寄せ、眼球ボーンの回転中心も合わせた。実メッシュで測った眼球間の距離は238.4mmから196.6mm、頬幅に対する比は0.500から0.412になった。規範6体は193.3〜200.6mm、比は0.360〜0.422。

`Review/eyes-and-chin.png` は原画2枚とVRMを正投影の+27°で比較したもの。全高500pxに揃えると、虹彩の中心間隔は原画95〜97px、立体72pxになる。手前のシアン領域は原画幅21px・VRM幅26px、奥はどちらも幅17px。原画の顔の占有率、斜視にしたときの奥行き、上瞼による隠れ方に差が残る。

下顎は顔・胸の接する中央を下げ、両端から中央への落差を12.4mmから19.9mmにした。母音など8表情の中間・最大の実際の顔面から、顎縁を置く深さを求めた。顎に沿った180点の正面投影で、開口50%・100%時に頬に隠れる点は旧版54点・66点、修正後はいずれも0点。開口100%時の表面からの距離は0.47〜1.03mmだった。
