# コアフォルダ #85 ハッコ

編集用ベースは `Corefolder-85-Refined.blend`。公式 CreationsDB の Num 85、`corefolder/85/emstk_corefolderNTS-85-{1,2}.png`、`catalog/chr-dsgn_catalogNTS-85.png`、`arts/corefolders/2023/art_imgNTS-85-corefolder.png` と照合した。

- **顔・耳・髪**　公式の茶髪・シアンの虹彩を #4 由来の表情付き顔に合わせた。中央へ長く落ちる前髪は、頭頂から一続きの面で額を覆い、左右に長短のある毛先と合わせ目を持つ。丸い側髪と側ポニーの根元は、実際に頭部の内部まで差し込み、奥行き方向にも曲げた。両耳の根元を後頭部に重ね、正面右斜めから見える右耳には白い開口・橙の内毛・茶色の折り返しを描いた。左右の高さ・倒れ方と後頭部の奥行きは立体化時の補間。
- **顔面の構成**　規範 #4 の実VRMの顔926頂点・15表情と、首・頭・左右眼骨を胸基準で配置した。虹彩の濃い上部と丸い下段の色面は瞼の内側、暖色の頬は顔のUV、下顎の境界は顔と胴が接する高さにある。下顎は左右端で細くなる。口はそれより上にあり、共通の仕上げで規範 #93 の口腔・舌・唇を反映した。
- **胴・付属品**　共通素体 `Basis/Corefolder/VRCModel_CoreFloder-Base.blend` のMirrorとSubdivisionを評価し、スターターの4,306頂点・8,608辺が一致することを確認して、原本の頂点座標に戻した。幅1,171mm・奥行959mm・高さ825mmだった胴は854×873×712mmになった。肩から頬へつながる褐色の面と球面UVの白腹を作り、側面に三角形に出ていた白い喉を頬の毛色につないだ。銀色の鎖は胸に沿って鎖骨から襟足側へ回る。水滴形のシアンの石には濃色の覆輪と吊り環があり、胸ボーンに追従する。茶色は公式 `#C48455` を起点に規範のUnityライトに合わせた。比較写真は `Review/structure-comparison.png`、16高さの断面は `Review/body-sections.json`。
- **可動部**　個別フック `design_85.revise(arm, collection)` がポニー主房・先の枝・左右の頬毛のガイドを返す。主房と枝は同じチェインで揺れる。尾の8房は `Tails-85.json` と `Tails-85.png` に基づく。2枚の公式表情で動く小さな口と、同位置に残る長い顎縁を区別し、口のモーフは共通の仕上げで #93 の口腔形状を参照する。
- **編集画像**　`paint_85.py` は Pillow と NumPy で胴・顔・首・耳左右・髪の UV を再生成する。耳は裏までつながった一枚の曲面で、髪の濃色は各房の先で細く消える。

## 原画と顔の比較

公式立ち絵2枚では、表情が変わっても両目の反射は画面の右上にある。左右の虹彩を別々の UV 領域へ展開し、両方の反射を同じ方向から描いた。虹彩の下段には#4・#25の実アトラスに見られる丸い色面を用いた。#25・#93の公式絵と実VRMを比べると、絵の頬の斜線はモデルでは淡い暖色と小さな白い反射になる。ハッコにもこの描法を用い、茶色を顔の側面へ回した。側髪は規範の目にかぶらないよう幅と奥行きを整え、毛束の裏面に薄い陰色を載せた。#22を含む6組の比較は `Corefolder-Training/production-review/reference-pairs.png`。

眼球スキンの中心間は#4と同じ200.62mm。中立時の上唇から18mm上の頬断面477.37mmに対する比は0.420で、規範6体は0.360〜0.422。まぶた・眼球・眼骨の回転中心には#4の実座標を使った。

`Review/eyes-and-chin.png` は原画2枚とVRMを正投影の+27°で比較したもの。全高500pxに揃えると、虹彩の中心間隔は原画95〜97px、立体73pxになる。手前のシアン領域は原画幅21px・VRM幅27px、奥は原画幅17px・VRM幅18px。原画の顔の占有率、斜視にしたときの奥行き、規範の上瞼による隠れ方に差が残る。

素体の胸と規範の頬が交わる位置に顎縁を置き、両端の頬面に沿って約13mm立ち上げた。両端から中央への落差は17.9mm。母音など8表情の中間・最大の実際の顔面から顎縁の深さを求めた。顎に沿った180点の正面投影で、中立・開口50%・100%時に頬に隠れる点はいずれも0。開口100%時の表面からの距離は0.33〜1.12mmだった。
