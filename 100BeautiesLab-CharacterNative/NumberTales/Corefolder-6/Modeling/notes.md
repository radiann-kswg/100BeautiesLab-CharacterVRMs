## 引き継いだ構造と変更点

- 編集用スターターは `verified-20261125/Corefolder-6/Corefolder-6-Starter.blend`。SHA-256 は `098ff6d3ece32abbd373b9ea21f717145b2185d114a9853c742bc39993508360`。
- 胴体の原本は `Basis/Corefolder/VRCModel_CoreFloder-Base.blend`。左右のスキンウェイトを保持し、共通の裸胴をムイの胴幅と奥行きに成形した。
- 骨格・顔・唇・まぶた・表情キー・顔 UV の出典は #4。胴の衣装、髪、耳、尾はムイ用の形状。元の顔のモーフに同じ座標変換を適用し、目の開きと口角を穏やかな基準表情に合わせた。
- スターターの胴の陰影規範は #16、顔は #4。全身を MToon 化し、顔はマスク付きアトラス、胴は左右対称の白い腹、六尾は境界の曲率に追従する毛先テクスチャを使用。画像は編集用データと VRM に内蔵した。
- 53 の Humanoid ボーン割当、表情にバインドのある 13 の VRM グループを持つ。左右の髪2房と狐尾6本は独立した Spring Bone チェイン。尾には胴に追従する衝突球が1個ある。ばねは規範 #93 の値に合わせ、尾の剛性 0.8、側髪 0.96、共に抗力 0.4、重力 0 とした。
- 正面で襟下端と「6」が白いお腹に隠れた初稿を修正し、背面中央の隙間、頬の房の見え方、前髪の分け目を正面・側面・背面で見直した。点群追加学習・画像モデル追加学習の実施回数はいずれも 0。今回の仕上げは実メッシュ、UV、マテリアル、骨とウェイトの編集によるもの。

## 原画との位置・面積比較

比較元は最初の個別制作版 `688effb8…`。額には原画1の両眼位置と頭の傾きを基準に抽出した桃色の髪を曲面へ投影した。内耳の開口は体の外側へ回し、尾は公式後面図の縦横を同じ縮尺で立体化した。胴の下腹を膨らませ、襟とブローチを上げた。編集用の房・印刷・留め具のパーツを、書き出し時に Body / Face / Hair / Tail の4メッシュへまとめた。79,684 三角形から 12,600 三角形になった。白頬は外縁だけを細い実線にして、顔と接する箇所のちらつきを抑えた。上唇・下唇・口腔の動作は共通工程で #16 の実モーフを参照して再構成した。

`Fit-Mui-Neutral.png` の上段は中立姿勢の同じ斜め角、下段は尾だけの背面。全高を揃え、左右中央と裾を合わせてアルファ輪郭の共通部分を比較した。上段の公式立ち絵は首を傾け、尾を開いている。尾の背面・全身の中立姿勢・参考ポーズは別々に判定した。

## 再生成

リポジトリ直下で実行する。テクスチャ原本は同梱済み。作り直す場合は Pillow と NumPy がある Python で最初のコマンドを実行する。最後のコマンドの `--out` には比較用の新しいディレクトリを指定できる。

```powershell
$mui = '100BeautiesLab-CharacterNative/NumberTales/Corefolder-6/Modeling'
$blender = 'C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe'
$database = 'D:/VisualStudio Code Userfile/100BeautiesLab_CreationsDB'
python "$mui/textures_6.py" --database $database
& $blender --background --offline-mode --disable-autoexec --python-exit-code 1 --python "$mui/model_6.py" -- --database $database --out '.cache/mui-rebuild'
```

別の場所にスターターを置いた場合は `model_6.py` に `--starter <.blend>` を渡す。スターターは `Corefolder-Training/create_corefolder_base.py` の `--number 6 --style 16 --material CoreFolder016.001 --face-style 4 --face-material CoreFolder004` で作成したものを使う。
