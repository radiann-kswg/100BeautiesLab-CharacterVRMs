## 編集と立体検証

ベースは `verified-20261125/Corefolder-6/Corefolder-6-Starter.blend`（SHA-256 `098ff6d3ece32abbd373b9ea21f717145b2185d114a9853c742bc39993508360`）。`canonical_face.py` が #4 実VRMの頭・首・両眼の骨、眼窩・瞼・頬の中立面と15の表情を対応づける。唇と口腔には #16 の実モーフを使う。左右の房と六尾は8本の独立した Spring Bone。#93 の実設定に合わせ、尾の剛性0.8、髪の剛性0.96、抗力0.4、重力0。書き出し後は Body / Face / Hair / Tail の4メッシュ、13,088三角形、6枚の画像を内蔵。新たな点群学習と画像学習はいずれも0回だよ。

最終の胴の幅は853.9 mm、高さ711.7 mm。編集用 `.blend` の中立スキンをワールドZで切った際の幅・奥行きは、床から100 mmで650.7・677.2 mm、370 mmで853.8・872.7 mm、630 mmで635.7・631.4 mm。同じ5断面の規範 #93 との差は幅0.0 mm、奥行き0.1–0.2 mm（0.1 mm丸め）。中間稿の最大幅960.3 mm、高さ786.4 mmから共通素体へ戻した。襟はこの肩の曲面に沿って背側を下げ、白頬は根元を顔に差し込み、外側の房だけを襟へ沿わせた。尾は後方へ伸びる量を三段で変えて、側面からも各房の付け根・膨らみ・先端が読めるようにした。

## 再生成

```powershell
$mui = '100BeautiesLab-CharacterNative/NumberTales/Corefolder-6/Modeling'
$blender = 'C:/Program Files (x86)/Steam/steamapps/common/Blender/blender.exe'
$database = 'D:/VisualStudio Code Userfile/100BeautiesLab_CreationsDB'
python "$mui/textures_6.py" --database $database
& $blender --background --offline-mode --disable-autoexec --python-exit-code 1 --python "$mui/model_6.py" -- --database $database --out '.cache/mui-rebuild'
```

別の場所にスターターがある場合は `--starter <.blend>` を指定する。テクスチャ生成にはPillowとNumPy、画像測定にはさらにSciPyを使う。`pose_view_6.py`、`fit_report_6.py`、`eye_report.py` にカメラと測定方法を記録したよ。
